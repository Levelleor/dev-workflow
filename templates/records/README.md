# Typed record templates

Frontmatter declares a stable ID, type, lifecycle state and explicit relationships. `agentctl work add` and `agentctl knowledge add/capture` now allocate IDs, validate supplied relationships and maintain category links.

Use [PRD](prd.md), [ADR](adr.md), or [story](story.md) as a starting point. Templates contain placeholders, not actual project decisions or accepted tasks.
