# dev-workflow knowledge base

Versioned knowledge for **this** project:

- [Product](product/README.md): accepted intent and product requirements.
- [Architecture](architecture/overview.md): system boundaries and intended design.
- [Decisions](decisions/README.md): durable ADRs, including resolved trade-offs.
- [Knowledge policy](knowledge/README.md): metadata, IDs, discovery and document lifecycle.
- [Work](work/README.md): planned features, dependencies and execution plans.

Every active record has a stable ID and navigable entry point. The initial manual index is intentional; generated indexes will be introduced when the knowledge CLI exists.
