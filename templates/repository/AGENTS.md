# Agent entry point

This repository is configured to use dev-workflow conventions.

Before work: inspect Git state, read the task and its parent requirements, follow linked decisions, and determine the applicable verification policy. Create a task or knowledge proposal if the appropriate authority is missing.

Do not invent acceptance evidence, reduce required test coverage, modify protected policy to pass checks or place private run state in Git.

Configuration: `.agentctl/project.yaml` and `.agentctl/checks.yaml`.
